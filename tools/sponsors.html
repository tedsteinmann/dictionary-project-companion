Project setup

Add public organizer details, the groups making your project possible, and any certificate redemption instructions.

Files stay in your browser. Download your configuration, then build the site with it. This setup page is not included in the published site.

Public organizer contact

These details are printed on the static Contact page. They are not a contact form.

Certificate redemption

Leave this off when the project has no certificate offer. No visitor information is collected.

Build your site

Run this command with the path to your downloaded file:

npm run build -- --config /path/to/site-config.json

Deploy dist/, or preview it with python3 -m http.server 4174 --directory dist.
