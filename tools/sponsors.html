Local build tool

Sponsor setup

Add the groups making your dictionary project possible. Choose a logo and add a title, description, and website for each sponsor.

Files stay in your browser. Download your configuration, then build the site with it. This setup page is not included in the published site.

Build your site

Run this command with the path to your downloaded file:

npm run build -- --config /path/to/sponsors.json

Deploy dist/, or preview it with python3 -m http.server 4174 --directory dist.
